# Текущее состояние проекта DekoRss (Current State)

## Описание проекта
Легковесный генератор полноценной Full-Text RSS-ленты блога LiveJournal (`dekodeko`) на **чистом Python**. 
Сформированный фид (`dekodeko_lj_feed.xml`) публикуется на GitHub Pages и предназначен для прямого чтения через RSS-ридеры (Inoreader, Feedly, NetNewsWire и др.) без необходимости в стороннем веб-интерфейсе.

---

## Архитектура и ключевые файлы

- `main_scraper.py` — основной и единственный исполняемый скрипт скрапера. Загружает блог, обходит возрастные ограничения 18+ (через куку `adult_explicit=1`), очищает HTML от мусора, нормализует смайлы, фильтрует нежелательные теги и формирует RSS 2.0 фид с CDATA-контентом.
- `.github/workflows/deploy.yml` — воркфлоу GitHub Actions:
  - Запускается по cron каждые 6 часов (`0 0/6 * * *`) либо вручную (`workflow_dispatch`).
  - Устанавливает зависимости (`beautifulsoup4`, `feedgen`, `python-dotenv`).
  - Выполняет `python main_scraper.py` и переносит сгенерированный XML в папку `docs/` для публикации на GitHub Pages.
  - Поддерживает активность репозитория (keepalive commit), предотвращая отключение расписания GitHub Actions.
- `dekodeko_lj_feed.xml` — локальный артефакт RSS-ленты с записями.
- `.env` / `.env.example` — переменные окружения (`LJ_URL`, `LJ_EXCLUDED_TAGS`).
- `README.md` — документация проекта.

## Последние выполненные изменения

### 1. Форматирование размера текста `(X.Xk)` (Вариант 2 — цветной бейдж)
- **Причина изменения:** В RSS-ридерах (Inoreader) тег заголовка `<title>` является строго plain-text полем, где HTML-теги вырезаются, а цвет принудительно задается интерфейсом читалки (жирный черный для непрочитанных, серый для прочитанных).
- **Реализация в `main_scraper.py`:**
  - Функция `format_post_content_with_badge(content, text)`:
    - Вычисляет размер чистого текста (без HTML) в килобайтах: `len(clean_text.encode('utf-8')) / 1024.0`.
    - Добавляет в самое начало тела статьи (`<description>` / `<content:encoded>`) стилизованный HTML-бейдж:
      ```html
      <div style="display:inline-block; color:#5a738e; background:rgba(90,115,142,0.1); border:1px solid rgba(90,115,142,0.25); border-radius:4px; padding:1px 7px; font-size:12px; font-weight:500; margin-bottom:10px;">(9.9k)</div>
      ```
    - Цвет выбран приглушенный серо-синий (`#5a738e`) с полупрозрачной подложкой: он визуально бледнее и мягче черного текста, но не теряется на фоне стандартного серого цвета прочитанных постов в Inoreader и отлично читается как в светлой, так и в темной теме.
    - Встроена защита от дублирования бейджей при повторных прогонах.
  - Из тега `<title>` черный текстовый префикс убран, благодаря чему заголовок в списке ленты остается чистым.

### 2. Полное удаление TypeScript / React / Node.js
- Удалена папка `src/` (React-компоненты, типы, стили и дублирующие функции очистки).
- Удалены серверные и конфигурационные файлы: `server.ts`, `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`, `metadata.json`.
- Проект полностью избавлен от лишних Node-зависимостей и приведен к первоначальному замыслу — чистому и автономному скрипту на Python.

### 3. Повышение надежности кэша (`load_existing_feed`)
- Функция `load_existing_feed()` переведена на встроенный модуль `xml.etree.ElementTree` вместо зависимости от стороннего парсера `lxml` в BeautifulSoup. Это гарантирует надежное чтение локального XML без предупреждений и ошибок отсутствия парсера.
