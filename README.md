# LiveJournal Full Text RSS Generator

Легковесный скрипт для автоматической генерации полноценной Full Text RSS-ленты блога LiveJournal (ЖЖ), даже если штатный RSS в блоге отключен или урезан.

## Преимущества и особенности

- **Без браузера и Playwright:** работает на сверхбыстрых нативных HTTP-запросах (~10 секунд на генерацию вместо 3–4 минут).
- **Без логина и пароля:** больше не нужно указывать свои учетные данные и проходить капчу LiveJournal.
- **Полный обход 18+ ограничений:** автоматическая загрузка полного текста постов через заголовок `adult_explicit=1`, исключая заглушки `(You are about to view content...)`.
- **Извлечение авторских тегов:** парсит теги непосредственно со страниц постов.
- **Умная фильтрация:** возможность исключать посты по нежелательным тегам (например, `#shorts`, `видео`).
- **Нормализация HTML:** очистка от лишних скриптов, стилей, приведение размеров эмодзи и смайлов к аккуратному виду.
- **Защита от засыпания (Keepalive):** GitHub Actions автоматически поддерживает активность репозитория, предотвращая отключение расписания cron через 60 дней.

## Переменные окружения (GitHub Secrets / .env)

В настройках репозитория (`Settings` → `Secrets and variables` → `Actions`):

| Переменная | Описание | Обязательна? | Пример |
|---|---|---|---|
| `LJ_URL` | URL блога ЖЖ | Да | `https://dekodeko.livejournal.com` |
| `LJ_EXCLUDED_TAGS` | Теги для исключения (через запятую) | Нет | `видео,#shorts` |

> ℹ️ **Логин и пароль больше не требуются!** Секреты `LJ_USERNAME` и `LJ_PASSWORD` можно удалить.

## Автоматическая публикация (GitHub Actions)

Воркфлоу `.github/workflows/deploy.yml`:
1. Запускается по расписанию каждые 6 часов (или вручную через кнопку `Run workflow`).
2. Устанавливает минимальные зависимости: `beautifulsoup4`, `feedgen`, `python-dotenv`.
3. Генерирует `dekodeko_lj_feed.xml` и публикует его на **GitHub Pages**.
4. Делает пустой коммит `keepalive`, чтобы GitHub не отключал cron-расписание при отсутствии ручных коммитов.

Адрес готового RSS-потока для читалок (Feedly, Inoreader, NetNewsWire и др.):
```
https://<ваш-логин>.github.io/DekoRss/dekodeko_lj_feed.xml
```

## Локальный запуск (по желанию)

```bash
# 1. Установка легковесных зависимостей
pip install beautifulsoup4 feedgen python-dotenv

# 2. Настройка переменных (или создайте .env)
export LJ_URL="https://dekodeko.livejournal.com"
export LJ_EXCLUDED_TAGS="видео,#shorts"

# 3. Запуск генератора
python main_scraper.py
```
Готовый файл появится в корне: `dekodeko_lj_feed.xml`.
